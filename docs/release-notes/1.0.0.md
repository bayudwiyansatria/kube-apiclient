### 📖 Overview

Kube API Client is a Java-based client library for interacting with Kubernetes clusters.
This is the initial stable release that provides core functionality for managing Kubernetes resources programmatically.

### 🚀 Features

- Kubernetes API integration
- Support for standard Kubernetes resources (Pods, Services, Deployments, etc.)
- Authentication mechanisms (API key, token-based, and certificate-based)
- Resource CRUD operations
- Namespace management
- Custom resource definition (CRD) support
- Asynchronous operations support
- Event watching and streaming capabilities

### 🔧 Enhancements

- Optimized connection pooling
- Improved error handling and validation
- Comprehensive logging support
- Configurable retry mechanisms
- Connection timeout management
- Resource pagination support
